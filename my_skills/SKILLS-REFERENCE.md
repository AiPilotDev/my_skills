## Matt Pocock skills (35 шт.)

### ⚙️ Настройка и роутинг
| Скилл | Что делает | Когда звать |
|---|---|---|
| **setup-matt-pocock-skills** | Разовая настройка репо для инженерных скиллов: где трекер задач, метки триажа, доки домена → пишет `docs/agents/*.md` | Один раз на репо, ПЕРЕД первым использованием других engineering-скиллов |
| **ask-matt** | Роутер: подбирает подходящий скилл/флоу под ситуацию | Пользователь не знает, какой скилл нужен |

### 🔄 Основной инженерный флоу (порядок)
1. **triage** — прогоняет issue/PR через конечный автомат: категоризация, верификация, «прожарка», agent-ready брифы
2. **to-spec** — превращает текущий разговор в спеку и публикует в трекер (без интервью)
3. **to-tickets** — ломает план/спеку на tracer-bullet тикеты с блокирующими зависимостями
4. **wayfinder** — планирование ОГРОМНОГО куска работы как карта решающих тикетов, разруливаемых по одному
5. **implement** — реализация работы по спеке/тикетам
6. **code-review** — ревью изменений с фиксированной точки (коммит/бранч/merge-base) по двум осям: Standards + Spec, параллельные саб-агенты

## Быстрые ответы на типовые вопросы

- **«Настрой флоу Покока в этом репо»** → `/setup-matt-pocock-skills`

- **«Напиши тесты / red-green»** → `tdd`
- **«Отревью мои изменения / PR»** → `code-review`

- **«Оцени архитектуру кодовой базы»** → `improve-codebase-architecture`

- **«Работа слишком большая»** → `wayfinder`
- **«Проверь мою идею на прочность»** → `grilling` / `grill-me`
- **«Передай контекст другому агенту»** → `handoff`
